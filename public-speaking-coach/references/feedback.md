# Reviewing a take: rubric and feedback format

## Evidence first
Run `review_take.py`, read `review.md`, look at every contact sheet (frames with timestamps), and read
the transcript. Every point cites a timestamp and either a number from review.md or what is visible in a
frame. No point without evidence; say "can't tell from this recording" when the camera or audio can't show it.

## Rubric (score each 1–5 for the setting: stage / camera / online)
| Area | Look at |
|---|---|
| Opening (first 30 s) | hook vs warm-up; energy vs the talk's median (`opening_vs_median`); eyes up? |
| Clarity of message | is the one sentence said? at start and end? points signposted? |
| Structure and time | time per section vs plan; overrun; rushed ending? |
| Pace | articulation wpm vs the stage target (profile − 10–15 %); rushed windows (> target + 25 %) |
| Pauses | beats before punchlines and at transitions (pauses ≥ 1 s per min); fillers instead of pauses |
| Vocal variety | pitch movement vs profile (stage wants +30–50 %); monotone stretches (`flat_runs`) |
| Volume / projection | loudness steady at the end (`ending_drop_db` ≤ 2 dB); contrast used on purpose |
| Fillers and restarts | per 1000 words vs profile; at sentence starts? |
| Stories and characters | performed (voice change, pause) or narrated flat? |
| Eyes | zones covered (stage), lens on key lines (camera), down/up at hook and close |
| Gestures | height (chest+), size for the setting, held to phrase end, fidgeting (ring, fingers, clicker, pockets) |
| Body / movement | planted on key points, moves on transitions; swaying, pacing, leaning on lectern |
| Face | smile at the right moments; face matches the content |
| Slides interaction | facing the audience; reading slides; clicker timing |
| Authenticity | still sounds like the profile? signature moves present? (guardrails §8 of the profile) |

## Feedback format (in the speaker's language; Tamer: Egyptian colloquial Arabic)
1. **الحاجات الحلوة**: 3–5 specific strengths with timestamps. Strengths first and concrete, so they repeat them.
2. **أهم 3 حاجات للمرة الجاية**: never more than 3 priorities per round. Each one: what happened
   (timestamp + number), why it matters in this setting, the exact fix («اسكت ثانية قبل…», «ارفع إيدك
   لمستوى الصدر في…»).
3. **باقي الملاحظات**: short list, lower priority.
4. **تمرين واحد** for the next rehearsal, tied to priority 1.
5. **قبل وبعد** (from the second take on): the numbers that moved (`--compare`), praise what improved.

Keep the voice: if a fix would make the speaker sound like someone else (MSA, shouting, generic opener),
drop it. Calm speakers get contrast (pauses, volume shifts, performed characters), not "more energy" everywhere.
