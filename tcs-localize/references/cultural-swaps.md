# Cultural adaptation

Swap only what would distract or mislead; never change a policy fact, limit or currency stated by the source.

| Element | EN default | Egypt / Arab adaptation | Rule |
|---|---|---|---|
| Names in examples | Mona, Alex, Sam | منى، كريم، سارة، عمر، نادين | use persona `display_name` when a persona speaks; neutral, common, non-celebrity |
| Currency | as source ($) | keep source currency; add local only if the source gives it (EGP / جنيه) | never convert amounts |
| Places | generic office, Alexandria (fictional example) | Cairo / Alexandria / New Capital offices | no real company sites |
| Holidays / time off | Christmas, Thanksgiving | Ramadan, Eid al-Fitr, Eid al-Adha, Sham El-Nessim, Coptic Christmas (7 Jan) | inclusive; avoid assuming one religion |
| Work week | Mon–Fri | Sun–Thu (most Egyptian/Gulf orgs), Fri–Sat weekend | check the org |
| Food/drink in scenes | wine, beer at dinners | tea, coffee, juice; keep the source's alcohol rule as a rule, show non-alcoholic visuals | sensitive visuals avoided |
| Dress / imagery | — | modest business attire, diverse incl. hijab/no hijab | flat vector personas already neutral |
| Gestures | thumbs-up, OK sign | thumbs-up OK; avoid pointing soles/feet, "OK" ring gesture | cartoon poses: prefer `present`, `point`, `cheer` |
| Phone/IDs in mock-ups | +1 555… | +20 1xx xxx xxxx (fictional), national ID never shown | fictional only |
| Dates | MM/DD | DD/MM or "1 مارس" | avoid numeric-only |
| Humour | puns, sarcasm | light situational humour; drop puns | in character |
| Hierarchy | first names with managers | "أستاذ/أستاذة" + name, "حضرتك" for managers/execs in dialogue | ar-EG dialogue |
| Ramadan scheduling | — | shorter hours; avoid food scenes in Ramadan releases | release-time note |

Process: list swaps per scene in the worklist `tr` (no separate file); note big swaps in `decisions.md` via the orchestrator.
