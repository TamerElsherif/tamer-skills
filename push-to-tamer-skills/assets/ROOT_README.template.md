# tamer-skills

Personal agent skills by Tamer Kamal ElSherif (IT·AI·BUSINESS) for Claude Code and compatible agents. Each folder is one skill: `SKILL.md` (instructions), `README.md` (what/when/install/use/examples), and a packaged `<name>.skill`.

## Install any skill
```bash
npx skills add TamerElsherif/tamer-skills --skill <name> --agent claude-code
```
Or copy the folder into `.claude/skills/` (project) or `~/.claude/skills/` (user).
